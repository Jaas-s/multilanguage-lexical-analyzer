# Multilanguage Lexical Analyzer

Proyecto académico orientado al análisis léxico para múltiples lenguajes de programación, implementado con Java y JFlex.

## Tecnologías
- Java
- JFlex

## Funcionalidades
- Tokenización de código fuente
- Soporte para Ruby, Go y C++
- Identificación de estructuras léxicas
- Procesamiento automatizado de entrada
